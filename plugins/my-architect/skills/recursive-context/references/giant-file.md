# Рецепт · Огромный одиночный артефакт (лог / дамп / транскрипт / документ)

Предусловие: размер-гейт сработал (>256 КБ или >5000 строк). Дисциплина из SKILL.md действует целиком.

## Шаги

1. **Проба структуры, не контента** (`Bash`): `wc -lc <file>`, `head -30`, `tail -10` — понять форму записи (лог-записи? реплики спикеров? секции?). Суммарный бюджет проб — ≤50 строк.
2. **Coarse-pass для needle-задач.** Если в вопросе есть конкретные якоря (код ошибки, имя, ID) — сперва `grep -n` по ним. Кандидаты + контекст влезают в <5000 строк → вырежи только эти регионы (`sed -n 'A,Bp'`) и отвечай напрямую, fan-out не нужен — так и скажи.
3. **Нарезка по естественным границам** в scratchpad: логи — по временным окнам или N записей; проза/транскрипт — по секциям/спикерам; структурные данные — по записям. Простейший вариант `split -l 20000 <file> <scratchpad>/chunk-`; для границ, не совпадающих со строками, — awk-однострочник. **Никогда не режь посреди записи.** Целься в 100–300 КБ на агентское чтение; лучше меньше выровненных чанков, чем много слепых.
4. **Fan-out каноническим скриптом** ([map-reduce-workflow.md](map-reduce-workflow.md)): `args = {chunks, question, batch}`. Узкий вопрос каждому; возврат по schema.
5. **Reduce** — loop-until-small уже внутри скрипта; на выходе малое множество находок.
6. **Синтез** с покрытием: сколько чанков обработано, что пропущено (и почему — в `log()` скрипта это уже зафиксировано).
