# Epic: Единый доверенный источник бренда (brand-source)

## Зачем

Сегодня атрибут бренда у контента приходит из трёх мест, и данные расходятся. Внедрение единого доверенного источника бренда создаст опору для авторизации, бэкенда, CMS и сегментации. Это стратегический шаг: он обеспечит гибкость и единый фундамент платформы на годы вперёд и разблокирует брендовые витрины.

Без доверенного источника полноценная сегментация невозможна.

## Ценность

- Появится коллекция brand_source и API-endpoint /v2/brand/resolve — результат работы.
- Страницы каталога станут значительно быстрее.
- Время резолва бренда — 50мс.
- Возможности нужны многим командам: контент, маркетинг, платформа.

## Как это работает сейчас

Для авторизованных пользователей резолв бренда уже работает через сессионный контекст — жалоб нет. Анонимный трафик получает бренд по умолчанию. Параллельно платформа мигрирует каталог на новый рендер-слой.

Технически: CDA-пайплайн доставляет атрибуты через ACP-шину с fallback на LCR-кэш.

## Если не делать

Технический долг будет накапливаться, и со временем будет плохо: поддержка усложнится, скорость разработки упадёт.
